# ** ESCAPE-ROOM CRIPTOGRAFIA **

Projeto-Jogo desenvolvido em JavaScript,Html e Css com o tema sobre Criptografia, com o intuito do ensino sobre Criptografia em um site criado por nós.

---

**Desenvolvedores**

---

**Como Iniciar**

Voce deve entrar no repositorio, baixar o arquivo ZIP, extrair o arquivo, abrir a pasta e entrar no arquivo INDEX.HTML

---
**Como Funciona:**

No site, voce verá mensagens criptografadas e um pequeno auxilio para ajuda-lo a descriptografar. No site voce terá como tentar adivinhar infinitas vezes, pedir uma dica extra e desistir da questão para aprender a descriptografar o site.
Com isso, voce aprenderá a descriptografar mensagens no estilo da Crifra de Cesar.
